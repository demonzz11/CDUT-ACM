## 题意

给出4个硬币的面值$c_1,c_2,c_3,c_4$以及`n`次询问每次给出$d_1,d_2,d_3,d_4$表示对应的4种硬币的数量，询问要买价值`s`元的物品的方案数

## 关键观察

- 1.如果只有一种硬币，可以使用完全背包，定义f[s]表示花费s元能得到的价值，算出s范围内f[s]的值，然后满足题意数量的部分可以$=$总数s部分减去不满足的部分，我们假设先拿出$d_i+1$枚硬币，那么剩下不论拿多少都是不合法的，所以合法部分就是$f[s-c*(d_{i}+1)]$

- 2.考虑4种硬币，如果对每种硬币都直接相减，那么会导致有重复部分被减去，考虑枚举每个二进制位，详细可以查询[容斥原理](https://oi-wiki.org/math/combinatorics/inclusion-exclusion-principle/)

- 3.我认为本题的难点是如何避免掉入多重背包的陷阱,想不到正难则反，而不是容斥原理

## 代码

```c++
include <bits/stdc++.h> 
using i64 = long long;
i64 f[100005], c[4], d[4];
void go() {
 for (int i = 0; i < 4; i++)
 std::cin >> c[i];
 int n;
 std::cin >> n;
 f[0] = 1;
 for (int i = 0; i < 4; i++) {
 for (int j = c[i]; j < 100005; j++) {
 f[j] += f[j - c[i]];
 }
 }
 while (n--) {
 for (int i = 0; i < 4; i++) {
 std::cin >> d[i];
 }
 i64 s;
 std::cin >> s;
 i64 ans = 0;
 for (int i = 0; i < 16; i++) {
 i64 res = 0, cnt = 0;
 for (int j = 0; j < 4; j++) {
 if (i >> j & 1) {
 res += (d[j] + 1) * c[j];
 cnt++;
 }
 }
 if (s - res >= 0) {
 if (cnt & 1) {
 ans -= f[s - res];
 } else {
 ans += f[s - res];
 }
 }
 }
 std::cout << ans << '\n';
 }
} 
int main() {
 std::ios::sync_with_stdio(false);
 std::cin.tie(nullptr);
 go();
 return 0;
}
```
